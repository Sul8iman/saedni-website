==================================================
SEND ONLY ONCE
==================================================

The welcome template must be sent only once per helper activation.

Add an idempotency field if necessary, for example:

helperWelcomeMessageSentAt

Behavior:

If helperWelcomeMessageSentAt is NULL:
→ attempt to send saedni_helper_welcome
→ on confirmed successful WhatsApp API acceptance, save timestamp

If it already contains a timestamp:
→ never send the welcome template again during login or repeated verification.

Do not mark it as sent before WhatsApp API accepts the template request.

==================================================
FAILURE BEHAVIOR
==================================================

WhatsApp welcome-message delivery MUST NOT block helper activation.

Correct sequence:

1. Verify OTP
2. Activate helper
3. Issue/prepare normal authentication
4. Attempt saedni_helper_welcome
5. If successful, record helperWelcomeMessageSentAt
6. If sending fails, helper remains activated and can use Saedni

Safely log the WhatsApp failure without exposing access tokens, OTPs, or sensitive user information.

Do not return an authentication failure just because the welcome template failed.
