## 1. Customer profile area wording

In the customer profile, change:

اختار منطقتك لتصلك الطلبات

to:

اختر منطقتك

The phrase “لتصلك الطلبات” is incorrect for customers because customers do not receive requests.

Check spelling everywhere and use:
اختر
not:
اختار

## 2. Customer multiple-area selection

Allow customers to select and save more than one Muscat area in their profile.

Requirements:

- Use the same active 16 Muscat areas.
- Allow selecting one or multiple areas.
- Display selected areas clearly in the customer profile.
- Customers must be able to edit their selected areas later.
- Validate selected areas on both mobile and backend.
- Do not accept inactive or outside-Muscat areas.
- Reuse the existing `preferred_areas` field if technically compatible; do not create a database migration unnecessarily.
- Preserve the existing primary `area` field for backward compatibility.
- Existing customer accounts must continue working without forced data loss.

Important distinction:

- A customer may save multiple preferred/profile areas.
- Each individual help request must still have one specific area only.
- Do not allow a single request to belong to multiple areas.
- Helper request visibility must continue using the single area selected for that request.
